# Liliia Tulupenko — Landing Page

Personal landing page for Liliia Tulupenko, PR & Communications Manager.

## Project structure

```
index.html              Main page
assets/
  css/style.css          Styles
  js/main.js             Site behavior
  js/shapes.js           Background animation
  images/main-photo.png  Portrait photo
```

## How it's hosted

This site is hosted for free with **GitHub Pages**, directly from this repository's `main` branch. There is no build step — whatever is in `index.html` and `assets/` is exactly what visitors see.

## Making changes

1. Edit `index.html` (text, links) or the files in `assets/` (styles, images).
2. Commit and push the change to the `main` branch.
3. GitHub Pages automatically rebuilds and publishes the update within about a minute — no extra steps needed.

If you're not comfortable editing code directly, you can also use GitHub's web editor: open the file on github.com, click the pencil icon, make your edit, and commit — no local setup required.

## Adding images

Put new images in `assets/images/`, then reference them in `index.html` as `assets/images/your-file.png`.

## Questions or bigger changes

For anything beyond small text/image tweaks (new sections, layout changes, forms), reach out to whoever built the site originally, or any web developer — the code is plain HTML/CSS/JS, so it's portable and easy for any developer to pick up.
